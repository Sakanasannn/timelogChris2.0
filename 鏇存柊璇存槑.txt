TimeLog + Chris v3 更新包

本包包含：
- index.html：个人资料区改为「打卡记录 / Chris 收藏」双标签，可折叠；只有新建 wake/sleep 打卡会触发台词弹窗。
- collection.js：特殊台词按节日、月初/月末、星期、季节优先级抽取；特殊台词全局只解锁一次；普通台词未收集优先；收藏记录解锁日期；兼容旧版仅 ID 的收藏状态。
- sw.js：缓存版本升级为 v3，HTML 优先网络请求，降低 GitHub Pages 持续显示旧页面的概率。

更新方式：
1. 先在旧应用导出 JSON 备份。
2. 在 GitHub 仓库根目录，用本包的 index.html、collection.js、sw.js 覆盖同名文件。
3. 保留 chris-lines.js、seasonal-lines.js、manifest.webmanifest、icon-192.png、icon-512.png，不要删除。
4. 等 GitHub Pages 部署完成后，强制刷新页面。新 Service Worker 会清理旧缓存。
5. 首次打开后检查浏览器控制台，确认 CHRIS_LINES.morning.length 和 CHRIS_LINES.night.length 都是 200。

说明：旧版收藏只有 ID、没有解锁日期的，升级后保留收藏，日期显示「日期未记录」。
